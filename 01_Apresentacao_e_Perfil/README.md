# Apresentação e perfil

Estudante de Engenharia da Computação no CEUB (Asa Norte), com interesse em desenvolvimento de software, dados e inteligência artificial. O Study Hub reúne atividades e projetos para apresentar minha evolução ao longo da graduação.

**Interesses principais:** Python, SQL, MySQL, desenvolvimento de soluções digitais, IA e conexão entre tecnologia e processos.

**Objetivo:** manter um histórico organizado do aprendizado, acessível por meio do GitHub e do GitHub Pages.
