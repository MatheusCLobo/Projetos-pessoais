# Colaboração e contribuições

O Study Hub e um trabalho individual de Bootcamp I, mas foi organizado para permitir colaboração futura.

## Proposta de fluxo

1. Abrir uma **issue** para registrar uma sugestao ou problema, sem incluir dados pessoais.
2. Criar uma **branch** separada da `main` para trabalhar na alteração.
3. Fazer commits pequenos, com mensagens compreensiveis.
4. Abrir um **pull request** explicando o objetivo e os arquivos modificados.
5. Revisar texto, links, segurança e resultado visual antes de integrar a alteração.
6. Depois da integração, verificar a publicação no GitHub Pages.

O dono do repositório decide se aceita contribuições externas e quem recebe permissao de escrita. Não e necessário convidar um colaborador artificial para cumprir uma etapa individual.

## Boas praticas

- Respeitar autoria, privacidade e licencas.
- Não incluir chaves, senhas ou documentos sem autorização.
- Descrever no pull request como a alteração foi testada.
- Em caso de dúvida, manter o projeto funcional e pedir revisão antes de publicar.
