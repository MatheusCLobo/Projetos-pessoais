# Publicação e checklist da entrega intermediária

## 1. Atualizar o repositório GitHub

Repositório utilizado: https://github.com/MatheusCLobo/Projetos-pessoais

1. Entre em sua conta do GitHub.
2. Faça uma cópia local do repositório existente com `git clone` ou abra-o no GitHub Desktop.
3. Extraia o ZIP entregue e copie **o conteúdo da pasta** para a raiz do repositório clonado. Mantenha a pasta oculta `.git` do repositório original (não a apague).
4. Confirme que `index.html` e `README.md` ficaram na **raiz**, não dentro de uma pasta adicional.
5. Confira o resultado com `git status`; em seguida faça commit e push conforme [versionamento.md](versionamento.md).
6. Abra o repositório e confirme se aparecem as pastas e o README atualizado.

> Esse procedimento atualiza `index.html`, `README.md` e outros arquivos da versão anterior do portfólio. Verifique os arquivos antes de substituir versões com alterações pessoais que você queira preservar.

## 2. Confirmar o GitHub Pages

Acesse **Settings > Pages** do repositório. Configure (ou confirme) a publicação com `Deploy from a branch`, branch `main` e pasta `/ (root)`. Aguarde a atualização no site: https://matheusclobo.github.io/Projetos-pessoais/ . A página nova deverá exibir o título **Study Hub**.

## 3. Integrar com LinkedIn

Abra seu perfil do LinkedIn > **Adicionar seção ao perfil** > **Recomendado > Adicionar destaque** (os nomes podem variar) e inclua o link do repositório ou do site. Uma descrição sugerida:

> Study Hub — portfólio acadêmico que organizei durante a graduação em Engenharia da Computação, com projetos, documentação e uma página publicada no GitHub Pages.

Registre o link público do seu perfil ou uma captura de tela do destaque para anexar como evidência, se necessário. **Essa integração ainda não foi verificada**.

## 4. Apresentação no YouTube

Grave uma apresentação de cerca de cinco minutos mostrando o repositório, o histórico de commits e a página funcionando. Utilize [roteiro-video.md](roteiro-video.md). Envie ao YouTube como vídeo público ou não listado e guarde a URL para inserir no PDF final.

O link `https://youtu.be/tNG-TWtbPsM` consta no documento da **primeira etapa**; não deve ser tratado como prova da apresentação nova sem conferir seu conteúdo.
