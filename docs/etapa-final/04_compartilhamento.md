O repositório e a página do Study Hub possuem enderecos públicos para consulta e apresentação profissional. O compartilhamento no LinkedIn foi feito na etapa intermediária, na seção de destaques do perfil do aluno.

- Repositório: https://github.com/MatheusCLobo/Projetos-pessoais
- Site: https://matheusclobo.github.io/Projetos-pessoais/

## Fluxo proposto de colaboração com GitHub

Para novas funcionalidades, a ideia e registrar o objetivo numa issue, criar uma branch, editar apenas os arquivos necessários, realizar um commit descritivo e abrir um pull request para revisão antes de integrar na `main`.

O trabalho e individual. Portanto, **não sera simulada uma colaboração externa**. Se um pull request de demonstração for criado, ele deve ser real e associado a uma alteração real, podendo ser do próprio aluno em branch separada.

## Controle de versão

O histórico do GitHub registra etapas da implementação, incluindo a publicação inicial e correções visuais na etapa intermediária. A publicação da documentação final deve gerar um novo commit identificado como etapa final, a ser conferido no histórico depois de efetivamente enviado.
