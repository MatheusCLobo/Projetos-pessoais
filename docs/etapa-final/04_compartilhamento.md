## Proposta de colaboração futura

O Study Hub é individual. Para uma eventual contribuição real de terceiros, o fluxo recomendado é: abrir uma issue, criar uma branch, trabalhar em commits pequenos, abrir um pull request, revisar o resultado e só então integrar na `main`. O procedimento está documentado em [`CONTRIBUTING.md`](../../CONTRIBUTING.md).

**Diferença entre planejamento e execução:** o fluxo com branch e pull request foi **documentado como prática recomendada**, mas não há alegação de que foi executado com uma equipe nesta etapa. Na verificação, não havia colaboradores adicionais e não existiam regras de proteção da branch.
