# Hackathons

Participação em competições de tecnologia com equipes multidisciplinares. Em uma delas, a equipe conquistou o terceiro lugar com uma solução digital para avaliação da confiabilidade de sites.

**Aprendizados:** colaboração, prototipagem, apresentação de ideias, definição de prioridades e desenvolvimento sob prazo.

**Situação neste portfólio:** resumo descritivo, sem publicar arquivos das equipes sem autorização.
