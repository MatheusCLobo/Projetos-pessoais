# UniData — Banco de Dados

**Contexto:** projeto acadêmico de banco de dados, com MySQL e modelagem de tabelas relacionadas para representar processos de uma instituição de ensino.

**Conteúdos trabalhados:** SQL, consultas, operações de dados, views, triggers e transações.

**Situação neste portfólio:** descrição do projeto. Os arquivos originais do banco não estão incluídos nesta entrega.
