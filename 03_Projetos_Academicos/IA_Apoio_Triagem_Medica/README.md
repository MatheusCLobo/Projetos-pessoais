# IA para apoio à triagem médica

**Contexto:** proposta acadêmica de empreendedorismo sobre o uso de inteligência artificial para organizar informações iniciais de pacientes e apoiar a triagem.

**Foco:** pesquisa de problema, desenho de proposta e discussão de aplicação responsável da tecnologia. Não constitui ferramenta clínica, não foi validada para uso médico e não inclui dados reais de pacientes.

**Situação neste portfólio:** descrição conceitual, sem implementação disponibilizada.
